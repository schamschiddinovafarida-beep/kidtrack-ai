KIDTRACK WEB — инструкция для Windows
====================================

Что это:
Веб-версия исходного Android KidTrack с сиренево-белым интерфейсом.
Сохранены идеи профиля, ручного ввода сна/шагов, целей. Добавлены AI-чат и AI-планировщик.
Геолокация намеренно НЕ перенесена: для образовательного MVP она не нужна и повышает риски для приватности детей.
Автоматического подсчета шагов, синхронизации телефонов и родительского контроля нет.

1. Установите Python с python.org (во время установки отметьте Add python.exe to PATH).
2. Распакуйте ZIP в обычную папку, например Рабочий стол\KidTrack_Web.
3. Дважды нажмите START_WINDOWS.bat.
4. Подождите установки Flask. В Chrome откроется http://127.0.0.1:5000
5. Не закрывайте черное окно: это локальный сервер. Для остановки нажмите Ctrl+C.

КАК ПОДКЛЮЧИТЬ НАСТОЯЩИЙ AI
---------------------------
AI не заработает без вашего API-ключа и доступа к интернету. Ключ не включен в архив.
Сервис использует OpenAI-совместимый endpoint. Для OpenAI подойдет URL по умолчанию.

В Windows PowerShell (откройте в папке проекта) введите:
  $env:KIDTRACK_API_KEY="ВАШ_КЛЮЧ"
  $env:KIDTRACK_MODEL="gpt-4o-mini"
  py -m pip install -r requirements.txt
  py server.py

Затем откройте http://127.0.0.1:5000
Ключ вводится ТОЛЬКО в PowerShell на компьютере с сервером. Не вставляйте его в HTML/JS, скриншоты или сообщения.
Для другого OpenAI-совместимого провайдера можно настроить KIDTRACK_API_URL и KIDTRACK_MODEL на сервере.
При отсутствии ключа сайт работает (профиль, цели, показатели), а AI честно показывает «AI требует настройки».

ДЕМОНСТРАЦИЯ ЖЮРИ
-----------------
1. Откройте Главную, покажите показатели и цели.
2. В Профиле поменяйте показатели и сохраните. Это только ручной ввод.
3. В AI-планировщике задайте время уроков и кружка, нажмите Создать план.
4. В AI-чате спросите: «Как распределить домашние задания и отдых?»
5. Объясните, что AI подключается через Python-сервер и работает с минимальным набором данных.

ПРИВАТНОСТЬ И ОГРАНИЧЕНИЯ
------------------------
* Профиль и цели сохраняются только в localStorage браузера; это НЕ защищенное хранилище и не предназначено для реальных чувствительных данных.
* На сервер не передаются профиль, шаги, имя и геолокация. В AI уходят только введенные вопрос или расписание.
* Вопрос и расписание передаются внешнему AI-провайдеру при включенном ключе: используйте вымышленные данные.
* Сервер не записывает историю чата, не содержит авторизации и рассчитан ТОЛЬКО на локальную демонстрацию.
* Не публикуйте сервер в интернет и не запускайте на 0.0.0.0 без отдельной разработки авторизации, защиты от злоупотреблений, HTTPS, политики хранения данных и согласий.
* AI может ошибаться; рекомендации не являются медицинскими советами.

Для хакатона MVP — рабочая демонстрация на одном компьютере. Перед публикацией реального продукта потребуется дополнительная безопасность и тестирование.
